Overview

Four system stages

Use short cards for orientation. Put the detailed explanation below, not inside these cards.

0 · Scope

Pin the input and compile policy.

Output: compiled request

1 · Evidence

Build the cited evidence view.

Output: evidence provider

2 · Reason

Prove requirements and solve candidates.

Output: candidate sequence

3 · Verify

Fit the output and apply hard gates.

Output: plan or typed stop

Tests

Stage verification gate

Keep the test method and negative behavior visible.

Method

Replay one pinned input and change one field at a time.

Good output

All references resolve and each hard gate passes.

Bad output

The system emits a partial plan or hides an unresolved requirement.

Minimum

One complete positive case and one typed negative case pass.
