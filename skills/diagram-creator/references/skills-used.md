# Skills used to create this toolkit

## drawio-skill

Source: <https://github.com/Agents365-ai/drawio-skill>

Used for:

- editable `.drawio` output;
- stable semantic identifiers;
- explicit edge geometry;
- structural validation;
- export and visual-inspection rules.

## asd-ste100

Source: <https://github.com/danyuchn/asd-ste100-skill>

Used for:

- short titles;
- one term for one concept;
- active voice;
- one instruction per sentence;
- removal of ambiguous phrasal verbs and noun clusters.

This toolkit uses STE-flavored wording. It does not claim certified ASD-STE100 compliance.

## design-taste-frontend

Installed repo skill: `.agents/skills/design-taste-frontend/SKILL.md`

Used for:

- equal content edges;
- fixed spacing and type scales;
- readable contrast;
- responsive visual containers;
- mandatory visual inspection at 1440, 1024, 768, and 390 px widths.

## doc

Installed skill: `~/.agents/skills/doc/SKILL.md`

Used for:
